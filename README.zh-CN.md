# 亚马逊卖家后台（Seller Central）用什么 IP：一个账户配一个静态 ISP IP（2026）

**每个卖家后台账户配一个自己的静态 ISP IP，账户在用多久，这条 IP 就留多久；只在专门服务这个账户的浏览器配置里打开卖家后台。** 员工在这个配置里用各自的卖家后台子用户登录，账户看到的始终是同一个地址，亚马逊自己的记录里也看得出每件事是谁做的。本仓库由 Proxy302 维护，我们出售文中这类代理。我们的亚马逊专用 ISP 就是为这件事做的：30 天 12 PTC（1 PTC = 1 美元），第一个 IP 半价（6 PTC），每个 IP 交付前都检测过，确认不是数据中心地址。普通静态 ISP IP 也能做同样的事：30 天 7.99 美元，或者花 0.50 美元先试 1 天。30 天及以上的静态 IP 为购买者独享。IP 只负责让合规账户的连接保持一致；谁能开店、一家企业能有几个账户、验证怎么通过，都由亚马逊决定，换哪条 IP 都改变不了。

## 1. 不管用什么 IP，这几件事都是亚马逊说了算

- **账户数量。** 卖家后台帮助里的《卖家行为准则》（Seller Code of Conduct）规定，一个销售地区原则上只保留一个卖家后台账户；只有业务上确实需要第二个、并且名下所有账户都状态良好时，才允许另开。每个账户单独一条 IP，并不构成这种需要。想开第二个账户，先问卖家支持（Seller Support）。
- **地区和站点。** 亚马逊把站点分成若干地区，一个卖家后台账户可以在同一地区的多个站点上架。IP 按账户数买，不按站点数买。
- **验证。** 身份和企业审核，看的是你交上去的证件和登记信息对不对得上，再加上亚马逊通知里点名的补充步骤。用哪个网络连进来，跟审核结果没有关系；材料本身有问题的，本文任何做法都帮不了。
- **位置。** IP 选在企业实际经营的地方，选定后不再换。IP 不能拿来把企业包装成在登记信息以外的地点经营。

## 2. 买之前先把对应关系写下来

把这张表写一次，后面大部分麻烦都能省掉：

| 卖家后台账户 | IP | 浏览器配置 | 在里面登录的人 |
|---|---|---|---|
| 账户 A（你在这个地区唯一的账户） | IP 1 | 办公电脑上的配置「A」，同一份配置也放在主管的笔记本上 | 店主和两名员工，各用自己的卖家后台子用户 |
| 账户 B（只有亚马逊确认你有正当需要时） | IP 2 | 配置「B」 | 这个账户自己的人 |

由这张表推出来的规矩：

- 一个账户、一条 IP、一个配置。两个账户绝不放进同一个配置，也绝不共用一条 IP。
- 员工在账户的配置里工作，用自己的子用户登录（卖家后台里「设置」下的「用户权限」）。主账户的密码和两步验证留在店主手上。
- 员工自己也开店的，他自己的账户放进另一个配置、用另一条 IP。

## 3. 亚马逊专用 ISP 还是普通静态 ISP

| | 亚马逊专用 ISP | 普通静态 ISP IP |
|---|---|---|
| 做什么用 | 登录卖家后台；交付前检测过，确认不是数据中心地址 | 任何需要长期登录的账户，亚马逊也可以 |
| 价格 | 30 天 12 PTC，第一个 IP 6 PTC | 1 天 0.50 美元，30 天 7.99 美元，各国同价 |
| 更长的租期 | 每 30 天续一次 | 还有 60 天 15.98 美元、90 天 23.97 美元 |

黑五（11 月 24 日至 12 月 1 日，UTC+8）：普通静态 ISP IP 60 天 14.00 美元、90 天 18.00 美元（1 到 30 天不变）。<!-- bf2026 -->

这条 IP 只服务卖家后台、并且看重交付前那道检测的，用亚马逊专用 ISP；同一家企业还在其他平台开店，或者打算先花 1 天走一遍流程的，用普通静态 ISP。两者在租期内地址都固定。动态住宅流量（1.50 美元/GB）只适合不登录的查看，例如以普通买家的身份去其他站点看自家商品的页面，卖家后台绝不经由它登录。能选哪些国家看订购页，所有价格见 [价格页](https://proxy302.com/pricing/)。

## 4. 配置步骤

1. **一个账户买一条 IP**，国家选企业实际经营所在的国家。静态 ISP IP 在购买时选 HTTP 或 SOCKS5；Chrome 等 Chromium 内核浏览器不能用账号密码登录 SOCKS5 代理，选 HTTP 最稳。
2. **用之前先看出口**（USER、PASS、HOST、PORT 是占位符）：

   ```bash
   curl -sS -x "http://USER:PASS@HOST:PORT" https://ipinfo.io/json
   ```

   `ip` 应与订单一致，`country` 是你买的国家，`org` 是网络运营商，而不是托管公司。
3. **给这个账户建浏览器配置**（单独的 Chrome 用户配置加代理扩展，或者指纹浏览器里的一个配置），把四项连接信息填进去，然后在这个配置里访问 `https://ipinfo.io/json`，和上一步终端里看到的对照。
4. **在这个配置里登录卖家后台**，两步验证用店主自己的手机或验证器完成。
5. **给员工开子用户**，只给他需要的权限，让他在同一个配置里工作。
6. **打开自动续费**，或者把到期日记进日历。续费还是同一条 IP；过期的 IP 会被收回，再下单就是新地址。

## 5. 每月花五分钟查一次

- 再跑一次第 2 步的 `curl`：`ip` 不应该变。
- 在控制台看一眼这条 IP 的到期日和自动续费开关。
- 在卖家后台检查子用户名单，离职的人删掉。
- 确认没人把这个账户的代理复制到别的配置里。

## 6. 把前面的功夫白费掉的做法

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 卖家后台不停发新登录提醒 | 有人绕开配置，在办公室网络或家里直接登录 | 只留配置这一个入口，卖家后台的书签只放在配置里 |
| 两个账户落到了同一个地址上 | 复制配置时连代理设置一起复制了 | 每个账户单独一条 IP，逐个配置查出口 |
| 某天配置突然连不上 | IP 租期到了 | 提前续费，或打开自动续费 |
| `org` 显示的是托管公司 | 误买了数据中心 IP | 换成亚马逊专用 ISP 或静态 ISP IP |
| 407 Proxy Authentication Required | 配置里用户名或密码填错 | 从控制台重新复制；HTTP 和 SOCKS5 要与购买时一致 |
| 员工把自己的店开在工作配置里 | 图方便 | 另建配置、另配 IP，最好另用一台设备 |

## 7. 常见问题

**同一个地区的几个站点，一条 IP 够吗？**
够。那是同一个卖家后台账户，就配一条 IP。

**员工在另一个国家办公，IP 选哪个国家？**
选企业经营所在的国家，账户在用多久就一直不换。员工在账户的配置里、用自己的卖家后台子用户登录，亚马逊自己的记录里就能看出每件事是谁做的。

**手机上能用亚马逊卖家 App 吗？**
你自己的账户、你自己的手机，属于正常使用。要避免的是在同一部手机或同一条 IP 上登录两个不同的卖家账户。

**亚马逊又要我验证身份，IP 能帮上忙吗？**
帮不上。按亚马逊通知里列的步骤，交真实、与登记信息一致的材料。

**有免费试用吗？**
没有。静态 ISP IP 1 天 0.50 美元；亚马逊专用 ISP 第一个 IP 半价。
